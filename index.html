Getting started

🏫
New class
Tap + New Class on the home screen to create your first class.
🧒
Add students
Inside a class, tap ⚙️ Settings → + Add Pupil, or import a whole class at once using a CSV file.
👆
Award a point
Tap any pupil card, then tap a behaviour category to award a point instantly.
👥
Group award
Tap Group, select multiple pupils, then tap Award points → to award them all at once.
📋
Board view
Tap 📋 to open the live leaderboard — great on a projector while you use the app on your iPad.
💾
Save your data
Tap Save in the top bar to download your data as a .db file. Load it again next time you open the app.

You can find this guide again at any time via the ⚙️ Settings button.
